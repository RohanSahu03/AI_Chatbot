# 🤖 GenAI Chatbot

A beginner-friendly Generative AI chatbot built using **Python, Ollama, and Gemma 3**.

This project is being developed step by step to understand the fundamentals of Generative AI and how to integrate Large Language Models (LLMs) into Python applications.

## 🚀 What I'm Learning

- Python for Generative AI
- Large Language Models (LLMs)
- Ollama and local LLMs
- Gemma 3
- Prompt engineering
- Conversation history and memory
- Context management
- LLM application development
- RAG and embeddings (coming soon)
- Vector databases (coming soon)
- AI agents and tool calling (coming soon)

## 🏗️ Current Architecture

User → Python → Ollama → Gemma 3 → AI Response

## 🎯 Goal

The goal of this project is to learn Generative AI by building a real application from the ground up, gradually progressing from a basic chatbot to more advanced concepts such as RAG, vector databases, tools, and AI agents.
